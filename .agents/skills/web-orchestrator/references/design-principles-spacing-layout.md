# Design Principles — Spacing & Layout (간격·레이아웃)

간격·터치 타깃·패딩·밀도·그리드의 수치 규칙이다. 토큰 값은 이 scale에서만 선택한다 — scale 밖 임의 값(13px, 18px 등)은 금지.

## 8pt 그리드와 spacing scale

- **모든 간격·크기는 8px 배수, 미세 조정만 4px 반단위** — 비정수 배율 디스플레이에서 홀수 값은 half-pixel 흐림을 유발한다. 아이콘-텍스트 같은 좁은 관계에만 4px.
- **spacing token: `4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 (+96)`** — 작은 값은 4px 간격(컴포넌트 내부), 큰 값은 8~16px 점프(레이아웃)로 위계가 시각적으로 구분된다. Carbon·Polaris·Atlassian이 모두 이 패턴에 수렴.
- **token은 9~12개로 제한** — 선택지를 줄여 일관성을 강제하는 것이 token 시스템의 목적.

## 버튼 간격·터치 타깃

| 항목 | 값 |
|---|---|
| 터치 타깃 | 44×44pt(Apple) / 48×48dp(Material), WCAG 2.2 AA 하한 24×24 CSS px |
| 실무 기준 | 데스크톱+모바일 겸용 웹은 40~48px 타깃, 24px는 절대 하한 |
| 인접 타깃 간격 | 최소 8px, 여유 레이아웃 16~24px |
| 버튼 그룹 | 그룹 내 8px, 그룹 사이 16~24px |

- **시각 크기와 히트 영역을 분리한다** — 아이콘은 24×24px로 그리되 투명 패딩으로 히트 영역을 44~48px까지 확장 (`24px 아이콘 + 사방 12px 패딩 = 48px`).
- **작은 타깃일수록 간격으로 보상한다** — WCAG 스페이싱 예외: 24px 미만 타깃은 중심 지름 24px 원이 이웃과 겹치지 않아야 한다.
- **파괴적 액션(삭제) 버튼은 주 버튼 쌍에서 16~24px 이상 벌린다** — 오조작 방지 (Fitts's Law의 역적용).

## 컴포넌트 내부 패딩

- **버튼 패딩은 좌우 = 상하의 약 2배** — 텍스트는 가로로 흐르므로 좌우 여유가 더 필요. 예: `6px 12px`, `10px 24px`. M3 filled button: 높이 40dp + 좌우 24dp.
- **카드 패딩 16px 기본** — 컴팩트 12px, 넓은 카드/마케팅 24~32px. 콘텐츠 폭이 커지면 패딩도 한 단계 올린다.
- **인풋: 높이 40~56px, 좌우 패딩 12~16px** — 고밀도 어드민 폼은 40px + 12px, 표준 폼은 48~56px + 16px.
- **내부 간격 ≤ 외부 간격 (불변식)** — 카드 패딩이 16px이면 카드 사이 간격은 16px 이상. 내부가 더 크면 소속 관계가 붕괴한다.

## 여백(whitespace)의 위계

- **3단 위계 고정: 요소 간 4~8px < 그룹 간 16~24px < 섹션 간 32~64px. 인접 단계는 최소 2배 차이** — 1.5배 미만 차이는 위계로 지각되지 않는다.
- **라벨은 자기 인풋에 4~8px, 다음 필드와는 16px 이상** (proximity) — 라벨이 위아래 인풋과 등거리면 소속이 모호해져 오입력을 유발한다.
- **긴 폼은 3~4개 필드씩 청킹, 그룹 사이 32px 이상** — 액션 버튼은 관련 콘텐츠 근처에 둔다 (tunnel vision 대응).
- **모바일 세로 스택 시 그룹 간격을 유지·확대한다** (24px → 32px) — 스택은 데스크톱에서 성립한 그룹 관계를 파괴하기 쉽다.

## 밀도(density) 모드

- **밀도 단계는 4px 감소 단위**: `height = 기본 + (4px × scale)`, scale 0/-1/-2/-3 (Material 공식). 그리드가 깨지지 않는다.
- **테이블 행 높이 표준(Carbon)**: compact 24 / short 32 / medium 40 / default 48 / tall 64px. 기본 쌍은 comfortable=48, compact=32.
  - 어드민 대시보드 테이블 32~40px + 셀 좌우 패딩 16px(compact 8px), 소비자용 리스트 48px. 24px는 마우스 전용 고밀도 화면에서만.
- **고밀도에서도 하한은 지킨다** — 행 내 액션 아이콘 히트 영역 24px 이상, 위젯 카드 사이 8px 미만 금지. 밀도는 반복 요소의 간격을 줄이는 것이지 위계·조작성을 없애는 게 아니다.
  - Grafana류 대시보드: 패널 간 8px, 패널 내부 패딩 8~12px, 섹션 여백 16px 이상.

## 레이아웃 그리드

- **12컬럼 유동 그리드 기본** — 컬럼 폭은 %, gutter/margin은 고정 px. 모바일 4컬럼 / 태블릿 8컬럼 / 데스크톱 12컬럼 운용.
- **gutter·margin: 모바일 16px, 태블릿 이상 24px** (허용값 8/16/24/40).
- **브레이크포인트는 업계 수렴값** — `600 / 905 / 1240 / 1440`(Material) 또는 `576 / 768 / 992 / 1200 / 1400`(Bootstrap). 임의 값 발명 금지.
- **컨테이너 max-width 1140~1320px, 본문 텍스트 컬럼 640~720px** — 대시보드는 max-width 없이 fluid + 패널 그리드, 문서형 페이지는 `max-width: 1280px; margin-inline: auto`.

## Gestalt → 간격 설계 규칙

1. **그룹핑의 1차 도구는 간격이다** — 구분선·박스를 추가하기 전에 간격 차이(2배 규칙)로 먼저 해결한다. 불필요한 구분선은 노이즈.
2. **경계·배경(common region)은 proximity보다 강한 신호** — 컨테이너에 넣으면 간격이 같아도 다르게 묶인다. 의도치 않은 배경 블록이 잘못된 그룹핑을 만들 수 있다.
3. **common region을 썼으면 내부 간격을 한 단계 줄일 수 있다** — 카드 없는 리스트는 그룹 간 32px 필요 → 카드로 감싸면 16px로 충분. 고밀도 대시보드에서 카드+8px 간격이 성립하는 이유.
