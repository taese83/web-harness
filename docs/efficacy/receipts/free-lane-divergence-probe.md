# 자유군 발산 프로브 — 타일 제약 해제 실측 receipt (2026-08-23)

`design-principles-research.md` §발산의 기계화의 **통제변인 규약(고정 DOM + tokens.css 13변수)이
방향 발산을 제약하는가**를 실측한 프로브. 통제군은 같은 브리프의 기존 타일 프로브
(`style-tile-divergence-probe.md`, 2026-08-19)이고, 이 문서는 자유군의 기록이다.

**결론 요약**: 사용자가 방향을 고른 결정적 근거가 **타일이 표현할 수 없는 차원**에 있었고,
자유군이 통제군보다 **쌌다**(33k vs 132k). 타일의 역할 재정의가 필요하다는 실측이다.

## 설계

| | 통제군(타일) | 자유군(이 프로브) |
|---|---|---|
| 브리프 | Grainhouse(필름 현상소 온라인 창구, 브랜드-포워드, 반레트로 긴장 제약) | **동일** |
| 표현 자유도 | `assets/style-tile.html` 고정 DOM(720px 단일 컬럼) + `tokens.css` 13변수 | 레이아웃·조판·모션·SVG 물성 전부 개방 |
| 산출 화면 | 추상 견본(색칩·타이포·버튼·폼 나열) | **실제 화면**(접수 현황 대시보드) |
| 후보 수 | 3 | 3 |
| 판정 주체 | 오케스트레이터 렌더 판정 | **사용자 육안** |
| 실행 | design-system-architect(sonnet 시점) 1회 | design-system-architect(**fable**) 1회 |

## 실측 수치

- **자유군 스폰: 33,381 tokens · 7 tool uses · 약 10분 · 완주**(후보 3종 + DIRECTIONS.md).
- 통제군: 132,616 tokens · 32 tool uses · 13.8분.
- **비용 역전 4배**. 단 동일 조건 비교가 아니다(정직 명세): 통제군은 sharded design-system
  문서·토큰·컴포넌트 인벤토리·README까지 산출했고, 자유군은 렌더 3종 + 방향 문서만 냈다.
  "자유 렌더는 비싸다"는 전제가 **최소한 자명하지는 않다**는 것이 이 수치의 주장 범위다.

## 후보와 선택

| 후보 | 방향 | 톤/밀도 | 에이전트 순위 |
|---|---|---|---|
| A | 계기반 — 암실을 작업 환경으로. 다크 + 세이프라이트 앰버(물리 근거) · 4세그먼트 공정 미터 · 그레인 오버레이 | 차가움/조밀 | 2 |
| B | 라이트 테이블 — 컨택트 시트가 곧 UI. 진행률 = 현상되어 드러난 프레임 수 · 그리스펜슬 마크 | 중성/여유 | **1** |
| C | 감광 기록지 — 필름을 측정 가능한 재료로. 특성곡선 위 플로팅 지점 · 비대칭 스티키 2컬럼 · 계측 조판 | 따뜻함/중간 | 3 |

**사용자 선택 경로(실측 — 에이전트 순위와 불일치)**: B 선호 → C 재평가("C가 가장 괜찮다") →
그래프 은유 기각("너무 이질적") → **최종 C3 = C 스타일 + A 구조**, 한글은 A 서체·영문은 C 서체.
즉 사용자는 후보 하나를 고른 것이 아니라 **축을 분해해 재조합**했다. 확정본:
`golden/design-refs/grainhouse-c3/index.html`.

## 이 실험의 핵심 데이터 — 타일이 표현할 수 없었던 것

사용자가 각 후보를 판단한 근거는 전부 13변수(색·폰트·radius·spacing·그림자) **밖**에 있었다:

- **상태 표시의 형식 자체** — 4세그먼트 미터 / 현상되어 드러나는 프레임 / 곡선 위 플로팅 지점.
  고정 DOM에서는 상태 컴포넌트의 *형식*을 발명할 수 없다.
- **레이아웃 원리** — 레일 앱셸 / 풀블리드 에디토리얼 / 비대칭 스티키 2컬럼. 방향 차이의 절반.
- **물성의 코드화** — 그레인 필터·스프로킷 홀·그리스펜슬 SVG. 색·폰트가 아닌 그래픽 차원에서
  반레트로 긴장을 푼 수단.
- **밀도 축** — 토큰 변형만으로는 거의 표현되지 않는다(타일은 DOM이 같아 밀도가 spacing 변수
  하나로 축소된다).

파일럿 2 부록 A-1의 "R1·R2 연속 기각(촌스럽다)"이 색이 아니라 **구성**에서 온 것이라는 가설과
정합한다 — 기각 사유가 발생하는 층위를 타일이 보여주지 못한다.

## 부수 실측 3건

1. **소유권 훅이 실험 경로를 막았다(설계대로 작동)**: `design-system-architect`는
   `_workspace/02_design/design-system*`만 소유하므로 scratchpad 쓰기가
   `enforce-agent-ownership`에 차단됐다. 에이전트는 **우회하지 않고** 산출물을 인라인 반환하고
   BLOCKER를 보고했다(오케스트레이터가 파일로 내려씀). 안전 장치의 정상 동작이자,
   "실험용 자유 경로 부재"라는 구조적 마찰의 실측이다.
2. **색 이식이 접근성을 조용히 깨뜨린다 — 기계 검사가 2건 검출**:
   - B→B2(레드→블루 이식): 스캔선이 밝은 프레임 위에서 **1.58:1**(하한 3.0 미달). 원본 레드는
     어두워 통과하던 것이 이식으로 깨졌다 → 페이퍼색 테두리로 해소(4.38/10.21).
   - A→C3(다크→밝은 표면 이식): 미완료 세그먼트 보더가 기본 배경 3.18:1로 통과하나
     **행 hover 배경 위 2.90:1** 미달 → 두 배경 모두 통과하는 값(#867e72, 3.49/3.19)으로 조정.
   둘 다 육안으로는 눈치채기 어려운 결함이고, 수기 계산이 아니라 **스크립트 산출**로 잡았다.
   최종 C3는 15/15 PASS(텍스트 4.5:1 · 비텍스트 3:1).
3. **혼합 서체의 함정**: Noto Serif KR은 한글 글리프도 포함하므로 `font-family` 폴백 나열만으로는
   "영문 세리프 + 한글 산세리프"가 성립하지 않는다(한글까지 세리프가 잡힌다).
   `@font-face` + `unicode-range`로 라틴 범위만 잘라 재명명해야 한다 — C3에 그 구현이 있다.

## 한계 (정직 명세)

- **단일 형태·단일 브리프**(브랜드-포워드 소비자). 어드민/대시보드 형태에서의 재현은 미실증이라
  이 receipt의 일반화는 **명명 수준**이다.
- 비용 비교는 산출물 범위가 달라 등가 비교가 아니다(위 §실측 수치).
- 판정은 사용자 1인의 취향이다 — "자유군이 더 낫다"는 통계가 아니라 **1건의 선호 실측**이다.
- 자유군 산출물은 렌더일 뿐 **디자인 시스템이 아니다**. 토큰·컴포넌트 인벤토리로의 추출은
  별도 작업이며 그 경로는 아직 밟지 않았다.
- Grainhouse는 eval fixture다 — 실사용 프로젝트에서의 완주는 별도.

## 후속 (이 receipt가 근거가 되는 것)

1. `design-principles-research.md` §발산의 기계화 개정 검토 — 타일 폐지가 아니라 **역할 재정의**
   (자유 렌더 = 방향 발산 정본 / 타일 = 토큰 축 통제 비교 + 접근성 하한 조기 탈락).
   I2 검토 필수: 타일의 내장 대비 검사가 조기 탈락 장치로서 실제 가치를 증명했으므로
   (통제군에서 상투 룩 FAIL 3건 검출) 이를 잃지 않는 형태여야 한다.
2. 자유 렌더 → design-system 토큰 추출 경로의 첫 실증.
3. 대비 검사 스크립트의 도구화 — 이 프로브에서 임시 스크립트로 2건을 잡았다. 발산·이식 단계의
   상시 검사로 승격할 가치가 있다(현재는 타일 내장 검사만 존재하고, 자유 렌더는 사각지대).
