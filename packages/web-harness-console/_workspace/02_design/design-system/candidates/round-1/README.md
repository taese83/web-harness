# 콘솔 디자인 개편 — 자유 렌더 후보 3종 (round-1)

같은 화면 1장(프로젝트 상세 + Overview, search-portal 실데이터)으로 세 방향을 주장한다.
529 폴백으로 main 세션이 직접 산출(execution-contract 폴백 조항, telemetry에 crashed 2회 기록).

## Candidate A — Gate Rail (계기판형)
- **정체성**: 증거-게이트 파이프라인(Source→…→Release)을 발광 게이트 레일로 상시 노출 — "게이트 도구"임이 화면 척추.
- **위계**: 상단 40%가 "지금 존" — NEXT 카드(다음 행동 2건)가 주인공, 통계는 아래로 물러남.
- **물성/원리**: 다크 슬레이트 + 상태 발광(통과=녹색 글로우, 진행=호박 펄스). 사이드바 프로젝트는 소형 게이지.

## Candidate B — Evidence Ledger (지면·타이포형)
- **정체성**: 감사 보고서의 조판 — 세리프 디스플레이, 이중 괘선, 번호 절(01~05), 스탬프형 승인 인장. "증거 원장"이라는 은유.
- **위계**: 타이포 스케일 + 최상단 "※ 검토 필요" 고지문 한 장 — 칩 대신 문장으로 다음 행동을 말함.
- **물성/원리**: 라이트 페이퍼, 플랫(그림자 없음), 난외주에 카운트. 사이드바는 얇은 목차.

## Candidate C — Ops Terminal (모노스페이스 물성)
- **정체성**: tmux/lazygit 계열 — 모노스페이스 전면, 1px 보더 페인 + 헤더바, `[PASS]`/`[STALE]` 토큰, ⌘K 힌트.
- **위계**: 최상단 `next>` REPL 줄이 곧 다음 행동(항상 첫 줄) + "attention" 포커스 페인(비면 진행 가능)이 유일한 강조색.
- **물성/원리**: 차콜 그린/앰버 포스포. 밀도는 의도적으로 높이되 강조는 포커스 페인 하나로 제한.
