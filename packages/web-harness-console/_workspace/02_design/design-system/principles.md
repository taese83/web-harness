# 원리 — 토큰에 없는 값을 정해야 할 때의 판단 근거

토큰 목록은 색표일 뿐이다. 아래 5원리는 승인 렌더가 실제로 내린 판단에서 추출했고, 새 화면·새 컴포넌트에서 토큰이 침묵할 때 결정의 근거가 된다. 각 원리에 렌더 속 증거를 병기한다.

## 1. 발광은 상태의 전유물이다

glow(`--glow-*`)는 **증거-게이트 상태 표현에만** 쓴다: 통과한 게이트·연결선, '지금' 게이트, 라이브 상태 점. hover 효과·카드 장식·브랜드 연출에 발광 금지 — 발광이 흔해지면 "여기가 파이프라인의 현재"라는 신호가 죽는다(희소성).
*렌더 증거*: glow는 `.gate.pass/.now`·`.link.done`에만 있고, 카드·버튼·hover 어디에도 없다.
파생 예: 라이브 헬스 칩이 "연결됨"을 발광으로 표현하는 것은 허용(상태), 선택된 프로젝트 행 발광은 금지(선택은 상태색이 아니라 표면 밝기 — 원리 3).

## 2. '지금'이 주인공이고, 색은 의미가 예약되어 있다 (강조 예산)

화면의 주인공은 **다음 행동**이다. Overview의 수직 순서는 레일 → 지금 존(NEXT+PULSE) → 탭 → 통계이며, 통계·이력은 항상 아래로 물러난다. 색 의미는 고정: **amber(--warn)=지금·행동 필요, green(--go)=증거 있는 통과, red(--stop)=실패·파괴, blue(--accent)=내비·선택·정보(비상태)**.
강조 예산: 한 화면에서 amber는 "지금" 의미 한 묶음(now 게이트 + NEXT 카드 보더 + amber filled 버튼 1개)까지. **amber filled 버튼은 화면당 1개**, 두 번째 행동부터는 테두리형(btn-s). red는 파괴·실패 외 사용 금지(빨간 취소 버튼 금지).
*렌더 증거*: amber 표면은 NEXT 존과 now 게이트뿐이고, filled 버튼도 `btn-p` 하나다. 헤더 refresh조차 테두리형이다.
파생 예: NEXT 행동이 0건이면 카드가 amber를 잃고 go-dim 보더의 "진행 가능" 상태가 된다(승인 대기 B).

## 3. 위계는 밝기 사다리다 — 새 표면은 사다리에서 고른다

다크에서 elevation·선택·집중은 그림자가 아니라 **표면 밝기**로 만든다: `--bg-deep → --bg → --panel → --card`(+히어로만 `--card-grad`). 새 표면이 필요하면 이 사다리의 인접 단계를 쓰고, **사다리 밖 밝기 발명 금지**. inset(코드 블록·트리)은 어두운 쪽으로, raised(카드·다이얼로그)는 밝은 쪽으로 한 단계.
*렌더 증거*: 사이드바(bg-deep) < 본문(bg) < 패널(panel) < 선택 행·카드(card). box-shadow는 상태 glow 외에 없다.
파생 예: 다이얼로그 표면 = `--panel`, 그 안의 컨텍스트 블록 = `--bg`(inset), backdrop = bg-deep 계열 반투명.

## 4. 숫자는 계기판 규율을 따른다

모든 카운트·시간·지속시간은 `font-variant-numeric: tabular-nums`. 계기 구성은 3층 고정: **오버라인 라벨(11px/800/+0.14em caps, faint) → 값(24px/700, text) → 보조 설명(12px, muted)**. 단위·분모는 값보다 작게(13px, faint)를 값 뒤에 인라인. 표의 숫자는 우측 정렬.
*렌더 증거*: `.stat`(k/v/d 3층), `.pulse b`·게이지 수치의 tabular-nums, `13 <span class=u>/ 21</span>`의 단위 축소.
파생 예: QA 히스토리 행의 시각·소요시간, 워크플로우 보드의 카운트 칩 — 전부 tabular-nums + faint 보조.

## 5. 물러남은 크기·명도로, 의미는 색+글자로

보조 정보는 **작은 크기 + faint/muted**로 물러나게 하되, 상태 의미는 **항상 색 + 텍스트(워드마크·아이콘) 병행** — 색 단독 전달 금지(WCAG 1.4.1). 읽는 텍스트의 하한은 `--faint`다: `--dim`은 어떤 크기에서도 텍스트 금지(대비 미달, accessibility.md). 게이지·바·점 같은 순수 그래픽은 반드시 인접한 상태 워드마크와 짝을 이룬다.
*렌더 증거*: 사이드바 게이지는 항상 `APPROVED/MISSING/ABSENT` 워드마크와 병행, PULSE 값은 색+텍스트, 게이트는 색+체크/숫자+라벨.
파생 예: 상태 칩은 dot+워드마크 병행(칩 색만으로 전달 금지), diff는 색+`+/-` 기호 병행.

## 파생 절차 (원리로도 못 정할 때)

1. **인접 토큰 스냅** — 필요한 값과 가장 가까운 토큰을 쓴다 (scale 밖 임의 값 금지).
2. **원칙 문서 기본값** — 허브 `design-principles.md`의 담당 절(간격·타이포·색·인터랙션) 기본값 적용.
3. 그래도 없으면 **결정을 기록**하고(components.md B 목록 또는 해당 스펙에 근거 한 줄) "승인 대기"로 표기한다. **추측을 승인된 사실로 위장하지 않는다.**
