# 접근성 계약 — 계산된 대비와 하한

모든 비율은 WCAG 2.x 상대휘도 산식으로 **직접 계산**했다(추정 아님, 수기 계산 — 반올림 ±0.05 허용). 기준: 일반 텍스트 4.5:1, 큰 텍스트(24px+ 또는 18.66px bold+) 3:1, 비텍스트(보더·아이콘·포커스 링) 3:1. 다크 배경은 WCAG 2 산식이 대비를 과대평가하므로 경계값(4.5~5.5)은 구현 시 APCA로 이중 확인 권장.

## 색 단독 전달 금지 (1.4.1)

상태는 항상 색 + 워드마크/기호/아이콘 병행: 게이트(색+체크·숫자+라벨), 게이지(색+워드마크), 칩(색+dot+워드마크), diff(색+`+/-`), verdict(색+PASS/FAIL 텍스트). 적녹색약에서 go/stop 구분이 색만으로 성립하지 않아도 정보 손실이 없어야 한다.

## Focus · 타깃 크기

- focus-visible: `outline: 2px solid var(--accent); outline-offset: 2px` — 전 인터랙티브 요소. offset이 배경을 노출하므로 amber 버튼 위에서도 링 대 배경 대비 성립.
- 타깃: 버튼 min-height 40px, 탭·터치 표면 44px, 인접 타깃 간격 ≥8px. WCAG 2.2 하한 24px 미만 금지. 사이드바 프로젝트 행 ≥40px.
- 스킵 링크 유지(현 콘솔 계승), 다이얼로그는 native `<dialog>` + 포커스 트랩 계승.

## 모션·강제 색상

- `prefers-reduced-motion: reduce`: 콘솔 전역 규칙(애니메이션 ≈0ms) 유지. pulse(--dur-pulse)는 정지 후 **정적 --glow-warn**으로 대체 — '지금' 게이트는 보더색+라벨이 병행하므로 정보 손실 없음. 스피너는 로딩 텍스트 병행.
- `forced-colors: active`: glow·그라디언트·틴트 배경 제거, 시스템 색 존중, 상태는 워드마크 텍스트가 전달(이미 병행 설계). 보더는 `1px solid` 유지로 구조 보존.
- 발광(glow)은 대비 계산에 산입하지 않는다 — 장식적 보강일 뿐, 판정은 항상 보더·텍스트 색으로.
