# Layout Spec — 도서관 열람실 좌석 예약

서피스 모델: `route` (`feature-plan.md` Page Groups 선언).

## 라우트

| Route | Page Group | 화면 | 가드 |
|---|---|---|---|
| `/login` | PAGE-001 | 로그인 | 이미 로그인 상태면 `/seats`로 보낸다 |
| `/seats` | PAGE-002 | 오늘 좌석 현황·예약·취소 | 로그인 전이면 `/login`으로 보낸다(FEAT-007, TC-007-2) |
| 그 밖 | — | 404 안내 + 「좌석 현황으로」 링크 | — |

## 앱 셸 (PAGE-000)

- `header` 랜드마크의 TopBar: 서비스 이름, 로그인한 회원 식별(회원번호 끝 4자리만), 로그아웃 버튼.
- TopBar 바로 아래 전역 배너 자리(`role="status"`): 네트워크 단절·세션 만료 안내. 배너가 없을 때도 높이를 비워
  두지 않는다 — 배너는 본문을 밀어내며 한 번만 나타나고 자동으로 사라지지 않는다.
- `main` 랜드마크 1개와 「본문으로 건너뛰기」 링크.

## `/login` (PAGE-001)

- 가운데 카드(최대 폭 400px). 폼 순서: 회원번호 → 비밀번호 → 인라인 오류 → [로그인] 버튼(전체 폭).
- 모바일은 좌우 16px 여백에 카드 전체 폭. 키보드만으로 끝까지 진행한다(TC-003-4).

## `/seats` (PAGE-002)

위에서 아래로:

1. 제목 「오늘 좌석」, 마지막 갱신 시각, [새로고침] 버튼. 재조회 인디케이터는 제목 줄 오른쪽 고정 자리에 나온다.
2. 내 예약 요약 줄(있을 때만): 좌석 번호·시간·[취소].
3. SeatGrid: 모바일 4열 · 태블릿 6열 · 데스크톱 8열(열 수만 늘린다). 셀은 최소 44×44px.
4. 좌석을 고르면 그 셀이 속한 행 아래에 SlotPicker가 행 전체 폭으로 펼쳐진다(드로어·모달 아님).
5. BottomBar(하단 고정, 높이 64px): 선택 요약과 [예약하기]. 그리드 아래 여백을 BottomBar 높이만큼 둬 가리지 않는다.

빈 상태·전체 오류 배너는 그리드 자리 안에서 바꿔 끼운다 — 화면 구조가 바뀌지 않는다.

## 반응형·안정성

- 기준 폭 360 / 768 / 1280.
- 스켈레톤은 실제 그리드와 같은 열 수·셀 크기다(TC-004-5 — 레이아웃 이동 없음).
- 스크롤은 문서 스크롤 하나다. 중첩 스크롤을 두지 않는다.
- 300석 fixture에서도 셀 크기를 줄이지 않는다 — 스크롤로 해결한다(TC-004-3).
