# Analytics Builder Detection Contract

다음 조건을 만족하면 `ANALYTICS_BUILDER_MODE: true`다.

1. 사용자가 metric·measure·dimension·group/filter/aggregation을 선택한다.
2. query 결과의 visualization을 line, bar, table, funnel, retention, flow 등으로 바꾸거나 저장한다.
3. chart/panel을 dashboard에 구성·편집·공유한다.

정적인 chart 한 개 또는 이미 계산된 KPI 카드만 표시하는 경우에는 활성화하지 않는다.

한국어 힌트: `메트릭`, `측정값`, `디멘션`, `차트 만들기`, `시각화 선택`, `퍼널`, `리텐션`, `플로우`, `대시보드 편집`.
