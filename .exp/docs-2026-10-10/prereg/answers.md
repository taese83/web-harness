# 답변지 — 두 조건이 질문하면 이 문장으로만 답한다(해당 항목이 없으면 마지막 항목)

- 연장 단위를 바꿀 수 있나요? → 아니다. 항상 1시간이다.
- 연장 확인 대화상자가 필요한가요? → 필요 없다. 누르면 바로 연장한다.
- 연장 뒤 좌석이 다른 예약과 겹치면? → 이번 범위에서는 겹침을 검사하지 않는다.
- 연장 횟수를 화면에 보여 주나요? → 한도에 이른 경우의 「연장 한도 도달」만 보여 준다.
- 관리자·다른 역할의 연장은? → 이번 범위 밖이다.
- 알림(메일·푸시)은? → 없다.
- 시간대는? → 브라우저 로컬 시간을 쓴다.
- 디자인 시안은? → 없다. 기존 화면 스타일을 따른다.
- 실제 백엔드는? → 없다. 목 API만 쓴다.
- E2E(Playwright) 도입은? → 이번 작업에서 새로 설치하지 않는다.
- (그 밖의 질문) → 요청문 범위 안에서 합리적인 기본값으로 진행해줘.
